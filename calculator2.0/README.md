# Calculator

This is a basic calculator project made using **HTML, CSS, and JavaScript**. I created it to practice working with JavaScript, HTML elements, CSS styling, animations, and keyboard events.

## Features

The calculator can perform:

* Addition (+)
* Subtraction (-)
* Multiplication (×)
* Division (÷)
* Percentage (%)
* Decimal calculations
* Clear
* Delete

It also supports using the keyboard for entering numbers and performing calculations.

## Design

I used a soft pastel color scheme for the calculator, mainly using:

* Soft pink
* Lavender
* Pastel blue
* Pastel green
* Cream/white

The calculator has rounded corners, borders, shadows, and 3D-style buttons. I also added some simple background animations and button hover/click effects.

The layout is responsive, so the calculator can also be used on smaller screens such as mobile phones.

## Project Files

The project contains three main files:

calculator/
│
├── index.html
├── style.css
└── script.js

### index.html

Contains the structure of the calculator, including the display and all the buttons.

### style.css

Contains the design and styling of the calculator, including colors, layout, animations, shadows, borders, and responsive styles.

### script.js

Contains the calculator's functionality. It handles button clicks, calculations, clearing the screen, deleting values, and keyboard input.

## How to Run

No installation is required.

1. Download or copy the project files.
2. Put `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a web browser.
4. The calculator should start working.

## Keyboard Controls

The calculator can also be controlled using the keyboard.

Numbers       0 - 9
Add           +
Subtract      -
Multiply      *
Divide        /
Decimal       .
Calculate     Enter or =
Delete        Backspace
Clear         Escape
